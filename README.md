# Proyecto Arboles - Estructura de Datos II

Proyecto Programado II del curso Estructura de Datos. Arbol binario de busqueda (ABB) construido a partir de una lista doblemente enlazada con valores aleatorios, en C++11 y sin contenedores de la STL.

## Compilar y ejecutar

```bash
g++ -std=c++11 -Wall -Wextra -pedantic *.cpp -o arboles
./arboles
```

## Como contribuir

1. Crear una rama propia a partir de `main` (por ejemplo `parte-2-derek`).
2. Trabajar solo en los archivos de la parte asignada.
3. Verificar que compila sin errores ni warnings con el comando de arriba.
4. Abrir un Pull Request hacia `main`. La rama `main` esta protegida: los cambios entran solo por PR aprobado por el lider del grupo.
